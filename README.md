## The Pipeline

```
Prompt -> Understand -> Plan -> Build -> Explain -> Learn
```

| Stage | What it does |
|-------|-------------|
| Understand | Analyzes the problem, target users, key features, and complexity |
| Plan | Full tech stack, database schema, API endpoints, dev phases |
| Build | Real starter code: Node.js backend, React frontend, SQL schema |
| Explain | Mentor-style breakdown of every architectural decision |
| Learn | Concept cards, tool recommendations, interactive quiz |

## Tech Stack

- **Groq API** - LLaMA 3.3 70B Versatile model
- **Streaming SSE** - Real-time response streaming
- **Vanilla JavaScript** - No frameworks, no bundlers
- **HTML5 + CSS3** - Single page, zero dependencies

## Setup

1. Clone the repo
```bash
git clone https://github.com/YOUR-USERNAME/appforge-ai.git
cd appforge-ai
```

2. Open `index.html` in your browser (or use Live Server in VS Code)

3. Click **Setup API** in the top right

4. Get a free Groq API key from [console.groq.com](https://console.groq.com/keys) (no credit card needed)

5. Paste the key and start building
